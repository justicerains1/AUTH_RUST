# ADR-NNNN：决策名称

- 状态：提议 / 接受 / 替代。
- 日期：YYYY-MM-DD。
- 关联任务与验收案例：Txx / Txx-CASE-NN。
- 决策者：待填写。
- 替代或被替代的 ADR：无 / 相对链接。

## 背景与约束

说明触发问题、已有文档契约、实际环境和必须保留的安全边界。

## 决策

写明具体选择、精确版本、适用范围及配置或接口影响。秘密值不得写入本文件。

## 备选与取舍

记录实际评估过的方案、证据及未采用原因；不以未验证的推测证明安全或性能。

## 验证与证据

列出真实执行的命令、退出码、版本和证据相对链接。没有执行的项目明确写未执行或阻塞。

## 影响与后续条件

说明升级、回滚、兼容和运维影响，以及需要同步修改的 plan.md / acceptance.md 段落。
