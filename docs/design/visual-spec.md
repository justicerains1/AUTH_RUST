## 设计变量

[机器可读 tokens](tokens.json) 延用 plan.md 第 8.2 节暖白 #F7F6F2、近黑 #171A1C、辅助 #5C6268、冷蓝 #2457D6、装饰框线 #D9DDE2；正文 16 px、控件 8 px 圆角、面板 16 px 圆角、4 px 间距基线。中文系统字体优先；不下载第三方品牌字体。桌面整体容器 1280 px，主布局以 12 列比例划分：首页 7/5、登录 6/6、安全中心侧导航 2/主区 10；手机改一列。

实测 #D9DDE2 对白色仅 1.364:1，保留它用于装饰分隔。输入及按钮需要可识别边界，增补 #70767D：对白色 4.589:1、对暖白 4.243:1，达到非文本 3:1。错误 #B42318、成功 #17623D 是反馈语义补充，必须同时显示图形及文字，不能仅凭颜色判断。详细公式与实测结果在 [contrast.json](../evidence/T15/contrast.json)。

| 组合 | 对比度 | 适用 |
|---|---|---|
| 正文 / 暖白 | 16.170:1 | 正文 |
| 辅助 / 暖白 | 5.708:1 | 辅助信息 |
| 蓝 / 暖白 | 5.696:1 | 链接与强调 |
| 白 / 蓝 | 6.160:1 | 主按钮文字 |
| 输入边界 / 白 | 4.589:1 | 控件识别 |
| 错误 / 白 | 6.574:1 | 错误文字 |
| 成功 / 白 | 7.366:1 | 成功文字 |

这是设计颜色组合验证，不声明完整 WCAG 2.2 AA 已验收。后续真实流程还需自动 axe 与键盘、屏幕阅读器、200% 缩放、焦点、对比度人工测试。

## 流程和状态

| 状态 | 视觉与文字 | 后续行为要求 |
|---|---|---|
| idle | 正常输入，主要操作清楚 | 显示 label、autocomplete；密码不持久化 |
| loading | 正在验证文字、禁用重复提交 | 不以动画完成作为前置 |
| success | 图形加完成文字 | 依赖真实 server 状态进入下一步；更新标题 |
| error | 错误图形、文字、输入边界 | aria-invalid 与 aria-describedby；保留非秘密输入 |
| limited | 等待时间和重试说明 | 依据服务端 Retry-After；不无休止自动提交 |
| unavailable | 失败说明、重新加载按钮 | 服务失败不能显示为已认证 |
| empty | 清楚空态说明 | 保留相关任务入口 |
| confirmation | 影响、取消、明确操作动词 | 初始焦点取消；限制并返回焦点；真实 API 完成后更新 |

验证码允许粘贴，autocomplete=one-time-code。登录密码 current-password，新密码 new-password。焦点环 3 px 蓝且外偏移 3 px；点击目标至少 44×44 px。手机不要求横向拖动才能完成任务；主要动作使用明确文字。

## 动效与成本

标准过渡 160 ms；减少动态效果时关闭位移、装饰动画、加载旋转，保留“正在验证”文字。本稿只用 HTML/CSS，无外部资源、远程字体、WebGL、视频或强制滚动。真实应用进入 T16 后必须以固定浏览器和网络条件验收体积及体验，不把此静态稿的加载时间冒充生产指标。
