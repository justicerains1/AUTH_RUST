# T14 真实管理员与 CLI 验收边界

真实 PostgreSQL identity_test 临时 schema、Redis、管理 HTTP 端点与编译后的 identity-admin-cli。初始化密码通过 stdin 传入，不放在命令行或环境变量；两个 CLI 进程并发初始化只有一个成功，再次初始化被拒绝；捕获输出检查密码及数据库秘密没有回显。CLI --test-schema 只接受显式 test 环境与白名单测试库的严格 schema 名称，不创建或清理其他数据库。

普通用户与未绑定因素的首个管理员不能访问管理组。首个管理员通过真实密码重新认证、TOTP enrollment 和独立 RFC TOTP 验证绑定因素，随后可调用管理端点；不是手工赋予 strong_at 的模拟认证。测试检查最后管理员删除/禁用被保护，用户与客户端停用、secret 轮换立即使凭证失效，强制审计错误回滚管理变更。

最后可用管理员的唯一 TOTP 不能自助删除；备管理员也通过真实 TOTP 验证后授予资格，两管理员同步删除自身因素仅一人成功、另一人409，数据库保持至少一名合格管理员。T08/T09 实际集成回归通过；T09 实体设备验收仍未执行。

本任务没有完成生产部署，也没有把未实现的管理员 UI 当作通过。实际结果见 integration.txt；早期空请求体测试错误及编译阶段失败记录保留。
