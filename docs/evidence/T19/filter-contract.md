# T19.01/T19.05 后台过滤与时间窗口子模块

T14管理API已通过，此子步骤为T19界面提供正式查询契约。用户页仅可选完整email精确规范化与active/disabled，审计页可选成对RFC3339 from/to（包含起点、不包含终点、最多31天）；没有任意SQL、排序或模糊通配搜索。无过滤仍默认20/max100按固定排序分页。

HMAC游标额外绑定过滤摘要，变更邮箱/状态/时间窗口不能复用旧游标。服务端参数重复、未知、非法编码/范围失败，仓储独立验证。OpenAPI同步两个已有GET操作，不新增未实现路由。

T19管理UI仍后续实施，当前子模块通过真实T14管理员API验证，不标整体T19完成。
