# CDNGOD隐私政策页面

新增公开路由`/privacy`及全站页脚“隐私政策”入口，沿用暖白/近黑/冷蓝与现有容器、面板、焦点和按钮规范。运营主体CDNGOD，联系邮箱support@cdngod.com由用户确认。页面七节说明账号/身份验证资料、用途、必要Cookie和浏览器秘密处理、应用授权与提供方、保存/安全、用户选择、联系和更新。

文案根据当前实现描述，不声称有自助注销/完整个人数据导出，不声称Passkey私钥或生物识别数据由平台收集；未确定的生产提供方、存储地域和保留期限明确待公布。联系邮箱只设置mailto链接，未发送邮件。此交付不代替正式运营政策审阅或生产发布验收。

实际TypeScript和定向ESLint0，原身份前端60单元测试全部通过，Vite production build0。当前Docker identity-web镜像重建并启动healthy，用户可直接访问http://localhost:5173/privacy。未更改后端/密钥/数据/端口和公网转发配置。

[实际浏览器报告](browser.json)为Chromium390/1440：无需登录且不发认证API请求，直接访问/刷新、目录锚点、页脚导航、CDNGOD文字/mailto准确，无横向溢出，axe违规0；[手机截图](privacy-390.png)、[桌面截图](privacy-1440.png)已保存。截图仅公开政策文字，不含账户秘密。
