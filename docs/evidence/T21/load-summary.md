# T21 后端负载独立子模块实测

四个场景均在本机实际执行两分钟预热、十五分钟测量，最终达到计划第 8.4 节对应延迟与速率门槛。此结论限于本机子模块，不将 T21 整体验收或生产发布标记通过：实际机器为 WSL2/Ryzen 7 7700X、16 logical CPU、15.217 GiB，API/PG/Redis/k6 同机，与参考 Linux 8 vCPU/16 GiB/SSD 不同，且 T20 实体设备等前置验收仍需完成。
