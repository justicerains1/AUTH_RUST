# T21 密码计算排队与并发实测指标

2026-10-08 UTC；本轮基于 cfc0c70 补充实现，实际提交由 Git 历史追踪。Argon2id 仍为64MiB、t=3、p=1，最多四个进程级任务、250ms等待截止，没有调整安全参数。

密码服务新增固定聚合指标：等待获取槽位的人数和高水位、已持有槽位的任务数及高水位、实际执行 Argon2 闭包的任务数及高水位、获取槽位等待时长累计值和1/5/10/25/50/100/250ms及+Inf累计桶。持有槽位包含等待 blocking 调度的任务，实际 running 只在计算闭包内增加，避免把两者混称实际并发。指标无邮箱、用户、令牌、IP或客户端标签。

等待统计包含成功获取、超时和取消的尝试；等待不一定表示发生排队，每次立即获取也计入耗时。初次初始化 dummy hash 在服务指标建立前运行，不包含在这些任务计数中。多个原子字段的读取不是瞬时一致快照，长期统计和高水位用于复查；不能据采样人数为零推定全过程没有等待。

真实 Argon2 单元测试验证原参数、共享全局预算、250ms超时、取消等待后人数恢复、取消计算调用后由阻塞任务保留槽位直到计算结束、累计桶单调和最终全部槽位释放。`cargo test -p identity-core --lib security::tests::argon2_real_hash_legacy_verify_dummy_reuse_and_global_queue_budget --locked`实际1通过、0失败、0ignored；原始输出 `.local/t21-password-wait-unit.txt`。

API `/metrics` 输出对应等待直方图和固定并发指标；实际T22集成确认新指标存在且空闲状态为零，API/Worker、密钥、备份/WAL/配置和签名轮换四阶段均退出0，见[T22记录](../T22/integration.json)。定向 Clippy（core/server所有target）退出0，完整负载期统计和最终统一回归另留证，不由单元或存在指标推定容量验收完成。
